UMKM Sales Dashboard (Excel)

Dashboard penjualan interaktif untuk UMKM alat tulis kantor (ATK), dibuat dengan Microsoft Excel. Dashboard ini membantu manajemen melihat kinerja penjualan dalam satu halaman.

Tentang Proyek
Data: 10.005 transaksi, Januari 2022 – Juni 2025
Tujuan: memantau penjualan, produk terlaris, kota, dan metode pembayaran
Tools: Microsoft Excel (PivotTable, PivotChart, Slicer, Timeline)
Isi Dashboard
KPI: Total Transaksi (10.005), Kuantitas (30.060), Total Sales (Rp647,4 juta), Grand Total (Rp935,7 juta)
Grafik: tren penjualan bulanan, distribusi metode pembayaran, transaksi per kota, penjualan per produk
Filter interaktif: Produk, Metode Pembayaran, Kota, dan Tanggal (Timeline)
Temuan Utama
Kalkulator Casio menyumbang sekitar 48% penjualan (Rp313,3 juta).
Denpasar dan Surabaya adalah kota dengan transaksi terbanyak.
Transfer adalah metode pembayaran paling sering dipakai (4.007 transaksi).
Penjualan tertinggi pada Maret, terendah pada Juli dan September.
Cara Menggunakan
Unduh dashboard_interaktif.xlsx.
Buka di Microsoft Excel 2013 atau lebih baru.
Buka sheet Dashboard, lalu gunakan slicer dan timeline untuk memfilter data.
Struktur File
Sheet	Isi
Data	Data transaksi mentah
Dashboard	Tampilan utama (KPI, grafik, filter)
Pivot	PivotTable sumber grafik
Reflection	Refleksi desain dashboard
